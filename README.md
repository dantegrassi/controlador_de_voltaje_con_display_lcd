Proyecto con Arduino UNO. Un controlador de Voltaje 0v - 5v. Uso de LEDs para indicar el Riesgo del voltaje y un Display LCD para mostrar el valor en tiempo real. Se ajusta mediante Potenciometro. 

Cosas Usadas:

-Kit Hemmel Arduino UNO R3

-Arduino IDE

-Potenciometro
-Microcontrolador Arduino UNO
-3 Led's (Rojo-Verde-Amarillo)
-X Cables Jumpers
-X Cables Jumpers Macho-Hembra
-Display LCD 16x2
-3 Resistencias 220
